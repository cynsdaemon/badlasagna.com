# Bad Lasagna Comic

**Bad Lasagna** is a cozy‑weird cosmic comic about bureaucracy, emotional labor, and the daemons who keep the universe running (poorly).  

The project is live at **[badlasagna.com](https://badlasagna.com)**.

This repo contains the full source for the site.  
It is a lightweight, static webcomic built with **Jekyll**, **HTML**, **CSS**, and **GitHub Pages**.
