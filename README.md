# Bad Lasagna Comic

**Bad Lasagna**, cozy‑weird comic about cosmic bureaucracy, emotional labor, and the daemons who run it. This project is live at [badlasagna.com](https://badlasagna.com). 

This repo contains the full source for the site. It's a simple lightweight, static webcomic built with **Jekyll**, **HTML**, **CSS**, and **GitHub Pages**.  


For **feedback and suggestions**, feel free to [open an issue on Github](https://github.com/cynsdaemon/badlasagna.com/issues) for this project. This project is built with love ❤️ coffee ☕ and an awesome playlist 🎵. Copyright © 2025 - Today
